# CHM Benchmark Explorer

A self-contained page (`index.html`) that maps and lists the 3Dtrees datasets used in the canopy height model (CHM) benchmark:
public datasets with an audited usable-area AOI, and datasets that could still be audited.

- Live page: https://3dtrees-earth.github.io/chm-benchmark-explorer/
- Rebuilt daily from the 3Dtrees database (read-only) and committed to this branch. The page states its data date.
- Biomes: RESOLVE Ecoregions 2017 (Dinerstein et al. 2017), CC BY 4.0. Land and borders: Natural Earth (public domain).
